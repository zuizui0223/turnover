# Jena TBE 2012: whole-trait-pool transfer of biodiversity components (2026-11-27)

## Motivation and scope
After DivResource 2013 PR #80 showed modest bidirectional out-of-pool gains for SE, TDCE and DE but not CE, test the same *component-specific transport question* in a distinct field programme: Wagg et al. (2017), Functional Ecology 31:2320–2329, DOI 10.1111/1365-2435.12945, original CC-BY-3.0 PANGAEA 876725. The Jena TBE previously analyzed in PR #74 has **known** high/low FD association results; this new prediction analysis is retrospective and is not independent confirmation of that original association. DivResource uses a fixed binary two-axis trait contrast, whereas Jena uses the original assigned high/low wFDc across differing resource-trait pools. Thus this is a test of the qualitative transport hypothesis, not exact metric replication. Jena pools are partially overlapping (20 unique species in 24 pool memberships, original paper reports four shared species). One field, not three sites. Overlap with Chen's meta-analysis source programmes remains unverified.

## Freeze before opening any new out-of-pool scores
- Reuse the unchanged PR #74 source assembler (SHA-256 458f61307df217d285c972f894ca5cf23709c3524dc6e13bb4d9dd3c26c2ab56), exactly 84 prequalified high/low matched mixtures in 6 pool×richness strata, 24 positive original pool×species monos, two original harvests 2012. No response-based exclusion. Replay previous full-cohort NDE, CE, SE WLS coefficients to 1e-8 before new prediction. Original 3-physical-block source gate remains HOLD; A/B/C Plot prefixes are **coding proxies only**. No original raw rows exported.
- Define B=sum Y, E=mean M, NDE=B−E. Relative yields r_i=Y_i/M_i, RYT=sum r_i. CE=(RYT−1)E; SE=B−RYT*E; DE=B/RYT−E; TDCE=SE−DE. Check identities NDE=CE+SE and SE=DE+TDCE, also TDCE=(RYT−1)*DE. Require positive RYT for each of 84 plots; if any zero, component-specific Fox comparison HOLD (do not invent DE or delete plots).
- Three leave-one-original-trait-pool-out folds. Train on two other pools, test on all eligible plots in held-out pool. If an identical original sown species roster occurs across pools, purge **training** rows sharing the held-out roster; never remove test rows. Count training/test shared species and exact compositions. No pool dummy: new pool mean cannot be estimated from its responses. Baseline M0 = intercept + categorical planted richness (all categories must appear in train/test) + two source plot-prefix coding indicators. M1 adds the same fixed high FD (wFDc 3/4 vs 1/2); no interactions, no new trait metric or outcome-informed scaling. Equal weight per training pool×richness stratum; equally weight heldout pool×richness cells when aggregating SSE. Require both models full rank in each fold; retain all outcomes.
- Primary qualitative transfer criterion: each of SE, TDCE, DE has positive incremental heldout gain in **all three** folds and pooled gain; report CE and NDE and B too, and paired SE−CE gain. Gain = 1−weighted SSE(M1)/weighted SSE(M0). Report raw fitted high−low coefficients by training fold. Fixed identical rows, weights and folds for all endpoints. Record component residual cross-products as accounting, no causal mechanism claimed. No population CI or p-values based on three dependent pools in one field. No selective reporting if criterion fails.
- Keep earlier PR #74 associations, DivResource #80 and Evolution RC4 fixed. No claim of K/rho causal mediation; one mono per species×pool limits baseline uncertainty. This is not a new independent biological sample relative to earlier use of the same Jena data.
