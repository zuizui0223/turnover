**Committed 2026-11-17 before ANY h1+leafN FD→biomass effect from this corrected source scale was opened.** The first frozen v0.1 attempt (Draft PR #59) remains permanently **SOURCE_SUPPORT_HOLD**, because it erroneously treated `traits.st.csv` columns `h1` and `leafN` as strictly positive original physical units and took `log(trait)`, although their source values are actually standardized. ## Original scale correction, diagnosed before any FD outcome

Official original van der Plas et al. 2020 author Figshare article `10.6084/m9.figshare.12834350.v1`, original `traits.st.csv` immutable file #24365039 (original bytes 47,135, MD5 `8045e7ee38f26b212dbe81aed0039765`):
- 59 original source taxa: `h1` 57 **finite SIGNED** values (37 negative, 20 positive), **mean 0, sample SD 1.000**, two missing; `leafN` all 59 finite signed (33 negative, 26 positive), mean 0, sample SD 1.000.
- **57/59** source taxa have both original supplied standardized values; requiring positive-only leaves only 5, a *source-scale misinterpretation*, not evidence of a biological scarcity.
- Original authors' public `main analysis.r` directly reads `traits.st.csv` and applies `imputePCA` to fill missing source traits before calculating Rao's Q and CWMs; does **not take log of h1 or leafN before trait FD**.
- **Use original signed standardized source values as supplied, without logarithms, truncation of negatives, arbitrary offset or outcome-guided imputation.** Source v0.2 deliberately leaves the two missing h1 values missing; no imputation introduced after source HOLD. Training-only re-standardization may be applied as specified below for fold comparability. Do not interpret signed source values as unstandardized cm or absolute leaf mg/g N.

## Predictive models and scoring — only after gate PASS

- The original predictor `h1` and `leafN` are already standardized source values. Apply `z=(original_signed_trait - mean_source_train_species) / SD_source_train_species` using original **training 2003–2009 source species only**; no `log` or extrapolated reference species value. Compute original **cover-weighted community CWM** for each; and one **2D Rao-style Q = `sum_{i<j} p_i p_j EuclideanDistance(z_i,z_j)`** with same original species and original cover weights in that source plot/year.
- **M0** = intercept + `log2(original sown richness)` + `CWM_h1` + `CWM_leafN`. **M1** = M0 + one `Q_2D`. Fit training-only source original **plot-equal weighted least squares** over 2003–2009; `Y=log1p(original plot×year `target_biomass_average` g dry matter/m²)`; one original response per plot/year, source response missing excluded from model fit/evaluation but **not** from predictor eligibility.
- Original heldout 2010/2011/2012 numeric response on plot-years with source covariates. Primary pooled original heldout `G=1−SSE(M1)/SSE(M0)`; annual G2010, G2011, G2012 separately. Directional positive requires original pooled G>0 **and each of 3 original calendar-year gains >0**, without looking for positive years after opening effects.
- Descriptive whole-original-plot bootstrap (10,000 draws, seed 20261117) resamples original plot identities as clusters across the 3 heldout years, **not three independent years or a site-level meta-analysis**; report as conditional uncertainty only. No new model/trait/threshold alternative after opening any effect.
- This is conditional on same-year observed original cover: not advance forecast before vegetation is measured. Not original TreeDivNet 6-site unseen-experiment transport. Negative original G would mean predictor generalization failure, NOT a negative FD–biomass ecological effect.
