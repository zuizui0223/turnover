## Frozen primary model
Response each original plot = **annual sum of original sown-species aboveground dry biomass in May and August 2012 (g dry mass/m²)**; weed, dead and unidentified material strictly excluded. The repeated monthly records are measurements of the *same plot*, not independent replicates.

Exposure `HighFD = 1[wFDc>=3]` versus `LowFD = 1[wFDc<=2]`, as determined by 2010 planting recipe, not postplanting measured FD. **Fixed primary** response `log1p(annual sown biomass g/m²)`; supplementary **raw annual biomass g/m²** under identical model and plots, regardless of result direction.

WLS with fixed one-total-weight per original **pool×sown-richness** stratum; a plot receives `1/n_stratum`. Design:
`Y_plot = intercept + C(pool × planted richness) + C(plot-prefix A/B/C) + beta * HighFD`.
Reference categorical levels lexicographically (source labels anonymized in outputs). No slope interactions, outlier winsorizing, richness transformation, alternative functional group selection, predictors using observed post-planting competitive dominance, or source result-targeted pooling. Full-rank and numerical condition no greater than 1e8 mandatory. Effect `beta` on `log1p` scale and ratio proxy `exp(beta)−1`; supplementary raw β in g/m². This is **NOT a formal FD mediation effect** because planted species identities and pool-specific design are bundled with FD.

**Uncertainty:** 2,000 stratified plot-level percentile bootstrap draws (seed 20261121), resampling original Plot IDs with replacement separately within each original pool×richness×HighFD cell. Refit the *same fixed WLS coefficients* on each resample; require >=90% successful full-rank bootstrap fits and report 95% interval of primary raw β and supplementary raw biomass β. No p-value or causal test; bootstrap assumes plots exchangeable within these assignment cells despite likely composition correlations. No 2012 month as replicate, no population inference beyond this site.

**Secondary diagnostic only:** report observed source distribution of high/low original mixtures within each of 6 pool×richness strata and fixed 3-prefix proxy; no 3-pool selection effect subgroup search, no multiple trait axes, no original Wagg 2017 CE/selection parameter refits rebranded new. There is no independent out-of-study transfer question within one Jena field; this pilot is explicitly within-study retrospective.

## Interpretation and hard firewall
This single-site Jena TBE trial is distinct from 2002 Jena Main, and unlike Chen452 study-heldout and Cadotte original same plot prediction, it **directly uses a treatment designed by functional traits**. Yet with no verified physical block identity and with species composition part of the assigned treatment, it only supports **source-condition-adjusted differences among deliberately chosen mixtures**, not independent randomization of continuous trait FD. In an effect-size positive case, cite Wagg et al. 2017 as **prior original published discovery**; in negative case, retain that result without selecting another exposure or model. Any positive result must not be characterized as a new general FD→biomass mechanism.
