# Abstract — Evolution submission draft

Phylogenetic signal is often discussed as a property of traits, yet the same trait can evolve differently in different clades. We therefore asked whether the **strength of phylogenetic trait memory** is itself transferable across lineages. Using a prospectively qualified crossed dataset of 201 family × trait systems spanning 45 vascular-plant families and 12 continuous traits, we contrasted two hypotheses. Under a trait-intrinsic hypothesis, the memory strength of a named trait should improve prediction in a completely unseen family. Under a lineage-context hypothesis, family identity should contribute a recurring cross-trait deviation in memory strength.

Trait-level portability was weak. Leave-one-family-out prediction using unshrunk trait means performed slightly worse than a global training mean, and training-only BLUP shrinkage removed most of that penalty without producing robust positive gain (S3 gain = 0.006; prune-only = −0.0048). In contrast, a family component near 0.15 persisted after species-level sampling-error correction, geometry and provenance adjustment, trait-domain collapse, and a predeclared correlated-trait zero-family-effect null (S3 p = 0.017; prune-only p = 0.009). Species-cluster bootstrap uncertainty further showed that roughly one quarter of typical total variation reflected finite-species estimation error, so the original residual could not be interpreted as biological system specificity. A complementary post-outcome analysis found no smooth organization of family context along deeper family phylogeny.

Thus, phylogenetic trait memory is lineage-contingent rather than a stable trait-intrinsic signature. Trait-specific evolutionary structure should not be borrowed across clades solely by trait name; its portability should be validated directly.
