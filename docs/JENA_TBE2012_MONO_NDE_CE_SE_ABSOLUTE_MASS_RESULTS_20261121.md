# Jena TBE: FDの違いはどこで生産量に現れるか — 単植期待量と混植利得の同一区画分解

**2026-11-21 / 原著オープンデータ実測・別々の固定モデル一致・非因果的な探索再解析。**

この解析で新たに直接確かめたのは「FDを強くした混植の収量差と、種を混ぜることで生まれた超過収量差は一致するか」という**同一区画の機構的な会計恒等式**であって、新しい無作為化実験ではない。元の [Wagg et al. 2017 *Functional Ecology*](https://doi.org/10.1111/1365-2435.12945) は**この実験の空間的・時間的形質差と補完性/競争格差を既に報告**している。元の科学的結果を再発見としては扱わない。

## 元データの直接照合

元の[PANGAEA 876725](https://doi.org/10.1594/PANGAEA.876725) 2012年の種別バイオマス、SHA256 `458f61307df217d285c972f894ca5cf23709c3524dc6e13bb4d9dd3c26c2ab56`。元の138区画×May/Augの276計測、うち**24単植区**（3種プール×8種、全て正の単植年間収量）と114混植区。事前のoriginal source criteriaを満たす**84混植区／6層**に限り、**同じ種プールの同じ種、同じ2012年の単植区**から期待生産量 `E = Σ M_i/R` を計算。全84混植区で元の `NDE=B−E` と `CE+SE=NDE` が一致。最大元区画の分解誤差は **2.3×10⁻¹³ g/m²**。別プール・別年の単植収量を借用していない。

元の実験デザインは高FD `wFDc=3/4`、低FD `wFDc=1/2` に分かれるが、**FDだけを無作為に割り付けていない（種組成も変わる）**。またPANGAEAの元の文字列 `Block` が一種類しかない一方、Plot IDのA/B/C系列は各46区画。三系列が著者の物理的な3つの空間ブロックに対応する原本 crosswalk は JEXIS #739 タイムアウトのため **未確定**。したがって同一プール×種数と原区画コードの3系列を条件化したWLSの**探索的関連**であり、FDの純粋な因果効果ではない。

## 84混植区における結果：高FD−低FD

| 同じ2012年の元実験からの応答 | 調整後高FD−低FDの点推定 (g乾物/m²) | 2000回original plot bootstrap 95%区間 |
|---|---:|---:|
| **単植収量からの期待量** `E` | **−33.62** | **[−94.17,+32.13]** |
| **混植による超過効果 NDE** | **+68.96** | **[−24.63,+163.53]** |
| └ 補完性 CE | **+27.81** | **[−47.63,+104.01]** |
| └ 選択 SE | **+41.15** | **[−26.80,+104.39]** |
| **実際の混植絶対バイオマス** `B` | **+35.34** | **[−76.28,+146.73]** |

**代数的整合性：**
`+35.341788 = (−33.619008) + (+68.960796)`。
`+68.960796 = (+27.814901) + (+41.145896)`。

両方の恒等式は**元の同じ84区画と同じ stratum×prefix WLS**で、別ブランチの観測絶対バイオマス係数＋35.34とCE/SE係数も元の値へ厳密に一致。元の単植期待量が低い方向と混植超過効果が高い方向は、同時に実現しうる。**ただし5つの95%区間はすべて0を含み、どの向きも統計的に明確といえない。** 「FDでCEが増えた」「FDでSEが増えた」「FDが低生産種を補償した」という確定的な生物学主張は禁止。別途SEとCEの差の95%区間も大きく重なり、どちらかの優位は未確定。

### 生態学的な読み取り

1. **混植の価値（NDE）と絶対バイオマスは、同じ指標ではない。** 種の単独生産力で決まる期待量 `E` が低い群集でも、種の混合による追加分が大きければ絶対バイオマスを補いうる。これは同じ単植データと混植データによる会計的な関係として実証できたが、「FDが因果的に補償した」という意味ではない。
2. **補完性だけが必要条件でも十分条件でもない。** 本試験ではCE+SE=NDEで、CEとSEの高FD差は両方正方向の点推定だが幅広い。原著Waggが示したプール固有の競争格差との関係は別の推定対象であり、今回のプール統合平均だけから特定しない。
3. **先行する全球メタデータ結果とも両立する。** [Chen452 PR #71](https://github.com/zuizui0223/turnover/pull/71) で葉窒素FDのCE/SE向け実験外予測は明確な正の一般化を示さず、[Cadotte PR #69](https://github.com/zuizui0223/turnover/pull/69) の追加FD予測も絶対バイオマスよりNDEで強くない。これらを一つの新しいメタ解析とみなさず、異なるestimandを厳密に区別する動機として利用する。

## 未解決の因果判定

元の `Block` の一種類記載と原著の三つの物理的ブロックを、**大学の正式な原設計表**で照合できていない。混植構成種とFDが完全に分離する無作為割付も証明できていない。単植区が種プール×種当たり実質1区画なので、**2000回の混植区ブートストラップCIは単植期待量自体の測定不確実性を再標本化していない**。元の24単植区を「24独立研究」とは扱わない。

本結果は独立した自然選択の機構実証でも、FD固有の原理の広域検証でもなく、**既報の1実験をソース完全一致で再解析し、同一区画の混植利得・単植期待量・総量が異なることを定量的に示す再現可能な限定付き結果**。
