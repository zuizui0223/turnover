## Retrospective fixed cross-study transfer estimand (after source gate)

One single principal question: **does a priori compiled leaf-nitrogen functional disparity provide better transferable *prediction increment* for complementarity CE than for selection SE?** Entire original study groups are withheld, not random rows.

- Use original *relative* `CE` and `SE` exactly as supplied (check their additive identity with `DY`). Signed, NO log/signed-log/offset or favorable response rescaling. Supplementary third response `CE−SE` is a deterministic **difference**, not an independent mechanism.
- M0 (same original plots/identical training and test folds for all responses): intercept + `log2(SR)` + `log1p(StandAge_year)` + supplied `PD` + source original planted-species `CWMLN` + `MAT` + `AI` + `FD_WithNFix` + two full-source categorical factors `Eco1` and `PlantType` (train-only fixed-dummy encoding with reference level; nonobserved categories at test mapped to the training reference), all numerical covariates standardized from **train only**.
- M1=M0 + the sole predeclared original planted species leaf-N Rao Q **`RaoQLN`**. No realized `RaoQLN_harvest`, `CWMLN_harvest`, no original biomass-inequality `FD_biomass`, no `SE_modified` in primary because its meaning is mathematically distinct. No interactions yet; no selection of favourable predictors, subsets or environmental range after outcomes.
- Main sensitivity is the predeclared **SLA** analogue with **`CWMSLA` and `RaoQSLA`** replacing only leaf-N counterparts on the separate originally published SLA source population (2,784 original rows, 247 original StudyID groups). Same source validity, CE/SE outcomes, fold and inference definitions. The two cohorts overlap, thus **NOT independent biological confirmation**.
- Model: simple **unpenalized weighted least squares**, each training original study assigned equal total weight (per-row weights 1/n_train(study)). All continuous covariates standardized using study-weighted training moments; categorical reference levels fixed lexicographically using train only. No outcome-informed feature selection, model degree, hyperparameter tuning, or recalibration of baseline/extra between CE and SE. Require full M1 column rank and numeric condition number ≤1e8 in each training fold, otherwise model-design HOLD, not drop difficult folds.
- Held-out prediction: **leave-one-original-StudyID-out**, all observations for that source study excluded from training. A study with unseen category is represented by reference category at prediction only; record these counts. Treat multiple measurements per study as non-independent.
- Primary metric: `gain_y = 1 − [Σ_study(SSE_M1,study / n_study)] / [Σ_study(SSE_M0,study / n_study)]` for y in (CE,SE,CE−SE); **paired contrast gain_CE − gain_SE** (dimensionless). Report number of original StudyID groups where per-study M1 error improves; do NOT use row-level bootstrap as independent. Study-balanced squared-error metric does not guarantee statistical significance or causal interpretation.
- Uncertainty: prespecified **2,000 StudyID-cluster paired bootstrap** resamples with replacement of the *fixed held-out error pairs* (seed 20261120). This quantifies uncertainty of those fixed fitted predictions; it **does not refit training across each bootstrap draw**. Report interval of each gain and paired CE-minus-SE contrast. Interpretation of CI bounded by source overlap and original selective filtering.
- Fixed result gate: numerical input source identity, all folds fitted and full-rank, 100% finite held-out predictions, both CE+SE identity and same-fold count pass. Report **all** results including zero/negative; no feature addition or source exclusion after first result, and do not claim p-values to infer original FD-induced ecosystem causal mechanisms.

## Distinguish published findings and potential new contribution

Authors already reported positive CE associations with leaf-N FD, PD, N-fixer mixture and age, and SE associations with monoculture yield inequality; even modified SE sensitivity was already tested. **No authors' bivariate relationship is new here.** The incremental question is whether FD adds reliable **across-original-study held-out predictive information** beyond phylogeny, richness, N-fixation, leaf-N CWM, study age, ecosystem and broad climate. A positive CE gain but not SE gain would be a *retrospective methodological generality finding*, not a new independent experimental FD causal effect. Negative CE/SE gains also scientifically informative and must stay in ledger.

The original manuscript CE/SE share percentages are global descriptive averages; never pool these with Cadotte 2017 one-study values as if 452+1 independent studies until source experimental overlap is checked. Dataset includes trait values from TRY; do not redistribute original files/raw species values. Only authors' original aggregate cohort counts, model scores and CI can be committed as JSON.

**NO K/rho→FD→CE/SE→biomass mediation is identified here.** Family phylogenetic memory score cannot be treated as independent pre-treatment assigned mediator. Science freeze means no searching for favourable ecosystem/microclimate interactions or treating source design hold as a biological null.
