# Independent Jena 2003–2012 trait × ecosystem-function time-portability: source-first screening

2026-11-17 **new source-first study**, before any new numeric functional-diversity/biomass response or model tuning. The original turnover general time-space gate remains terminal HOLD, and previous retrospective BIODEPTH/TreeDivNet source results and original `main` are not changed.

## Why this source now?

The completed TreeDivNet 2026 same-plot SLA+LNCM FD experiment adds **−34.9%** (six-source-site equal mean heldout SSE gain, original source) beyond species richness and plot trait means for **absolute woody stock**. Its negative heldout-site prediction score does not contradict Jensen et al. 2026's positive FDis–net diversity effect (different FDis, target and validation scope). We must not repeatedly retune TreeDivNet axes, thresholds or sites after viewing this result.

The **independent Jena Main grassland experiment** (2003–2012, 78 original plots, 60 sown species, 41 measured/compiled plant traits, 42 ecosystem functions) provides longitudinal biomass and ecosystem functions **at a different site and system**. Original study van der Plas et al. (2020) `10.1038/s41559-020-01316-9` reports mean cross-property explained variance **32.6% within individual years vs 12.7% across years** when using many traits, and mean **4.8% across-year** explained variance in the six-trait analysis. A 2022 Scientific Correspondence `10.1038/s41559-022-01920-x` criticizes indiscriminate trait/response matching and describes stronger prediction for mechanistically linked properties. **Both analyses use the same Jena experiment and are NOT two independent ecological datasets or randomized tests of trait selection.**

Prefer original authors' Figshare where possible. Never use PANGAEA repackaging as an independent replication of Figshare/Jena.

### First: meta/file access gate (zero biological responses)

For source Figshare articles 12834350 and 19087640:
1. Use the **official anonymous `api.figshare.com/v2/articles/<ID>`** API. Pin ID, DOI/root-or-version, version, metadata title, public date, license, file ID/name/size/MD5, no signed URL text, no original rows copied.
2. Check only file download HEAD (and a size-bounded Range response if HEAD fails) for exact source file ID URLs on official `ndownloader.figshare.com/files/<ID>`; no alternate commercial mirrors, no login token bypass.
3. Classify original publication's community-composition table, original plot×season/year woody/herbaceous biomass, species trait matrix, ecosystem property table, model scripts, and the 2022 response analysis by advertised **file names only**, never assume a file contains biological raw rows based on a short label.
4. No original analysis test until source files (not just a PANGAEA binary summary) are **verifiably anonymously available** and original plot ID/year/species and matching ecosystem-function response grains can be audited.

### Scientific source-qualification rules (for a separate *frozen* future effect study)

- Retain **unique original Jena plot×year×season** biomass **as its own response**, and unique original plot×year for each other ecosystem property. Never treat 78 plots×10y as ~780 independent grassland ecosystems; 2003–2012 repeated years are within the same 78 plots.
- Original species-specific trait values may be literature/monoculture or pot measurements rather than **actual plot-local traits**. Flag trait origin. Do **not** label source family K as measured by this Jena 59-species trait matrix alone.
- Jena 78 Main grassland plots are a **different experiment from TreeDivNet 2026 forest** but may overlap the turnover repository's earlier Jena **82 plots / May biomass** trait-guild archival study. This source is **NOT independent of earlier Jena original observations**, so before any predictive model, compare exact original study IDs/time/source publication and restrict independent-replication claims appropriately.
- Prospective longitudinal question: is added FD predictive value more **time-transportable when original traits were preselected for mechanistic relevance to the response**, vs matching only generic broad trait summaries? Predeclare relevant trait/outcome mapping using original trait ontology and outcome process, and register negative controls *before opening any new response scores*. No favorable functional/temporal subgroup searches.
- For a post-source study of true **out-of-year** prediction, freeze earlier years for training and later years heldout, and plot-blocked crossvalidation within the time split to prevent leakage. Different *time* validation from TreeDivNet whole-*site* holdout, so **never compare SSE gains or R² directly as if same estimand**.
- The exact original BIEN/AusTraits family-specific K→FD→biomass mediation requires broad independently qualified within-family species+trait support, unavailable in a 59-species Jena experiment, so do not substitute taxonomic PD or plant trait FD.
