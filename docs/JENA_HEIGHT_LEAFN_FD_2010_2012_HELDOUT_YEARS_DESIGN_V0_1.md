# Jena original 2003–2012: fixed cross-year plant height + leaf-N FD to original target biomass

**Original new outcome design frozen 2026-11-17 BEFORE any new FD vs biomass source values were fit.** The preceding original-source audits proved 78 exact canonical Jena main plot codes, **851/851 original plot-year keys** shared by biomass, cover and original function table, 59/59 original plant-trait species codes directly mapping to cover/biomass, and **847/851 original `target_biomass_average` numerically available**. No new trait-vs-biomass correlation or predictor-score was opened in those source-only phases.

## Why and what this does NOT test

The previous TreeDivNet **six-study, 113 original woody plots** found original plot-local SLA×LNCM FD worsened out-of-original-study woody-stock prediction by −34.9% conditional on species richness and CWMs (same original Jensen 2026 data). It did not test whether **reference species trait diversity** can predict grassland function in **future years** of the same plots, a different predictor measurement and validation target. The original van der Plas et al. 2020 Jena study already reported moderate within-year explained variance but poor across-year traits/functional patterns, and a 2022 reply argues biologically matching traits to target functions can improve performance; BOTH reuse the same Jena experiment and overlap prior Jena data in turnover. This new test is **exploratory, retrospective and one original grassland study**, not independent confirmation of the original published study results or a global phylogenetic K→FD→mass test.

- Each unique original `plot×year` produces one **source-conditional contemporary** community trait predictor from original *same-year vegetation cover* and original **species-level source reference** (`h1` height, `leafN` leaf nitrogen) from 59 species (not in situ plot-local traits). This is a **nowcast conditional on contemporaneously observed plant community**, **NOT a forecast before same-year cover was measured**.

For each plot-year, require ≥2 original species in both axes and ≥**80% of positive original cover weight** contributed by the source species with both traits, and original `sowndiv` a positive integer. Source 2004 summer missingness must be reported, not silently recoded as actual plant absence, and cover prior missing code handling exactly documented.

## Prespecified primary one-direction test

**Mechanistic source trait pair**: height `h1` and leaf N `leafN`. Height reflects light/space acquisition, leaf N assimilation/nutrient economics, both plausibly connected to **aboveground biomass**. This pair is predeclared based on broad ecology, not chosen after testing which trait pair performed best.

Within each plot-year:
- Species weight `p_i = mean adjusted cover_i / sum_j mean adjusted cover_j` among **positive-cover species with valid h1 and leafN**; minimum original cover weight coverage .8. Covariate context is observed **current-year** cover; never use original species biomass as species weights.
- Trait transform `z_i = (log trait_i - training original source trait mean) / training source trait SD`. Training trait summary based **only on source species present with positive cover in 2003–2009**, not heldout years.
- Original trait CWMs = `sum_i p_i z_{i,h1}` and `sum_i p_i z_{i,leafN}`.
- A *two-axis Rao-style cover-weighted FD* = `Q_2D = sum_{i<j} p_i p_j sqrt((z_hi-z_hj)^2+(z_Ni-z_Nj)^2)` (matches the original authors' `Rao Q` all-pairs/2 summation convention; not the 2D unweighted mean-pairwise FD in TreeDivNet).
- **M0:** `1+log2(original sown richness)+CWM_h1+CWM_leafN`. **M1:** M0+one `Q_2D`. Fit weighted least squares using full training 2003–2009 original source site/year records. Equal original-plot training weight `1/n_training_years_observed_in_that_plot` so plots with more observed source years do not dominate; no plot fixed-effect or outcome-fitted year term that would be undefined at unseen years. No model selection, nonlinearity or response-driven missingness.
- Primary heldout score **`1−SSE(M1)/SSE(M0)`** pooled across all source years 2010–2012 on log1p target, plus separately report source 2010, 2011, 2012 scores. A directional positive result requires pooled gain >0 **and all three annual gains >0**, with 10,000 *whole original plot* cluster bootstrap for descriptive uncertainty (seed 20261117). Bootstrap is conditional on these three source years and cannot estimate global interannual population uncertainty. No nominal p-value based on 3 future years.
- **Model source geometry stop:** M0 rank 4 and M1 rank5 on all training source records, training source trait SD >0, nonconstant FD predictor, no heldout target leakage. Otherwise status `MODEL_GEOMETRY_HOLD`, no new effect. No new trait-pair/season reruns after opening results.

## Contrasts and boundaries

This is time-heldout **within original Jena**; TreeDivNet test is site-heldout **between forest studies**. Never compare raw percentage SSE gains or null confidence intervals as if they share a population/estimand. The Jena 2020 published `FD` uses all 41 trait-specific RaoQ measures after regularized PCA source trait imputation; our *predeclared two-trait RaoQ* does not replicate original multi-trait imputed authors' published R². The original author data may condition derived CWM/FD rows on biomass >0: **do not reuse `predictors_raw.csv` as prospective test-year features**. Authors' 2022 reply is a new interpretation of the same source.

No phylogenetic tree, family Blomberg K, BIEN rho or evolutionary memory tested here. The PANGAEA original 2020 synthesis and Figshare are duplicate Jena records. No original 2003–2012 source file or biological response rows are committed to GitHub, only source counts, source-derived features in ephemeral runner, and final aggregate original-plot/heldout-year scores. Main unchanged, historical BIEN/GloBI terminal HOLD gates untouched.
