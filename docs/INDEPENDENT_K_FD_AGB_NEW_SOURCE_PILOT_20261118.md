# Independent-original source pilot after TreeDivNet and BIODEPTH closed (2026-11-18)

**Source-only contract fixed before opening any new source numeric trait–biomass effects.** The original TreeDivNet same-site measured SLA+LNCM FD increment failed six-/five-study site holdout (−34.91%, −106.19%, Draft #57) and will NOT be retuned; BIODEPTH one-axis observed-height and GBOTB community PD source programme also remains retrospective with no positive transferable FD effect. The prior global BIEN×sPlotOpen 201-system joint source gate is terminal HOLD, not reopened.

## Why new sources are necessary

A direct original trait-specific phylogenetic-memory K→functional diversity FD→plot biomass test requires **same source species taxonomy, species-level traits, original site×plot composition, a plot-level source AGB response, a dated native tree and enough independent families/sites**. Original GBOTB mean patristic distance is not family-specific K; precomputed CWM/FDis is not original species-level traits. No independent source must be declared to satisfy these unless actual downloadable raw data and original-matched taxonomic support prove it.

## Candidate A: new multi-forest independent source, original Zenodo record

**Original DOI:** `10.5281/zenodo.19609795` (Ali, 2026, *Plant-trait syndromes and environmental filtering drive biomass ecology in resource-limited forest ecosystems*). Official public `https://zenodo.org/api/records/19609795` lists two source files: `Forest_AGB_Data. Final.csv` (67.6kB, advertised MD5 `c3ffed15932611dca604dcd9e67d9bb8`) and `README Dataset Description.txt` (1.7kB, MD5 `6f0e782ec7968d35f5ee5f5539124b24`). Metadata claims original field-based aboveground biomass, functional diversity/dominance, environmental and forest type covariates. **Actual original CSV schema and grain are not known yet**. This is a *new original forest programme*, not a data continuation of Jensen or Hector.

**Access preflight:** fetch the official Zenodo API record and validate exact record ID, DOI root, public access, immutable file key/size and checksum. Download only original source file entries from the API **official Zenodo-hosted URLs**, ≤1MB each, verify original MD5 and never export original rows. Read CSV schema, row count, missingness/validity for *candidate* original plot ID, site, year, species taxon, biomass, precomputed functional diversity, environmental/forest covariates. Report original distinct sites/plots only when exact candidate key fields are unambiguous. Treat single-file plot-level trait index as derived; **do not claim** locally measured species traits if no original taxon×species trait rows exist. Never evaluate FD–biomass correlation in this gate.

**Admission for next separately frozen original mass model:** ≥3 independently named original forest sites/regions with ≥8 unique source plots each; ≥30 unique plot-level **observed** stand AGB values; >=20 named original plant species with at least two positive *directly measured* traits and exact same-plot species rosters and dates. A separate family-K gate must demonstrate original ≥12 disjoint source families with ≥20 independent species per family (≥240 source taxa), not simply import AusTraits or BIEN without new portability validation. Precomputed forest FD/CWM with absent original species×plot measurements gets status `PLOT_SUMMARY_ONLY_HOLD`, even if a plot-level productivity field exists. The point of this independent pilot is actual source eligibility, not a positive association.

## Candidate B: independent dryland experiment Dryad

**DOI:** `10.5061/dryad.mpg4f4rh5` (Boettiger et al. 2026 *What we measure matters*, grassland drought/irrigation). Official dataset advertises `Species_Trait_Values.csv` (9 species-level traits), `Cover.csv` (plot×year species cover), six precomputed FD/CWM trait suites and temporal biomass stability analysis from a **single regional drought experiment** in Boulder, Colorado. Published paper says 36 species. Before any model claim, verify original raw **annual aboveground biomass per `block×plot×year`** is in the same publicly released source bundle; a published plot-year FD table or figure with biomass trajectories is not itself independent original biomass observation. Source access may give 401/403; do NOT bypass Dryad restrictions. No original family-K inference with only ~36 species; any qualifying FD–mass analysis would be within one experimental programme and cannot be described as across-region site transfer.

## Candidate C: independently public measured-trait community archive lacking biomass

**DOI:** `10.5281/zenodo.19710211` Bauer et al. original GREEEN prairie, pinned GitHub tag `markus1bauer/2025_greeen_prairie@v0.2.0` tree SHA `365f2cb4a68b429fee400586ca48050230d4cbe4`. Metadata verified directly from original public repository: `data/processed/data_processed_sites_metadata.csv` has original plot×site/year, treatments, richness, percent vegetation cover, water capacity; `data_processed_species_metadata.csv` original species cover, original plot/site; `data_processed_traits_metadata.csv` species height/SLA/seed mass (some source TRY/GRooT) and `data_processed_traits_measured.csv` direct primary measured subset **only 3 species**. **No original measured aboveground stand biomass variable is advertised in the original repo's published data file or metadata list**. Original cover is **not biomass**. This candidate remains `ORIGINAL_STAND_AGB_ABSENT_HOLD` for the current question while useful for trait/cover source research.

## Source gates and epistemic limits

- All new data access is **source-only**, with exact IDs, checksum provenance, CSV headers, source grains, completeness, no response-effect fits, no data-dependent trait choice.
- Distinguish **independent experiment** from original published authors' own effect reuse; distinct original study + distinct source data is not itself independent verification of K→FD→AGB.
- Predeclared statuses: `SOURCE_GRANULARITY_PASS`, `PLOT_SUMMARY_ONLY_HOLD`, `SOURCE_BIOMASS_MISSING_HOLD`, `SOURCE_SITE_SUPPORT_HOLD`, `SOURCE_TAXON_TRAIT_SUPPORT_HOLD`, `AUTH_HOLD`, `DATA_ACCESS_HOLD`, `SOURCE_IDENTITY_HOLD`. No threshold relaxation or positive-subgroup search after opening.
- Original source traits, original plotted woody carbon and dry matter, modeled/harvested biomass and live production remain different ecological endpoints; distinguish from satellite-derived products and from original same-study reported results. A metadata-only qualified research hypothesis never becomes an ecological result without original source point-level and allometric provenance.
- Do not commit original biological data rows, trait values, original source files, API credentials, transient file URLs or private uploads. Archive only source schema/hash/count diagnostics and no-effect verdict, in an independent Draft PR based on `main`.
