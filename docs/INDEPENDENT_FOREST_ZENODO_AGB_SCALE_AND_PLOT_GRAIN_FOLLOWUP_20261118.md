### Specific source quality question

**What does the field called `AGB` mean?** Real aboveground biomass dry mass or carbon biomass cannot be negative. A 157/200 negative original field demands checking the original README for an explicit standardization/normalization statement. Many other variables (CWM, FDis, even Latitude/Longitude) also contain negative values; do not interpret original standardized numeric coordinates as actual geographic coordinates or ordinary units. If the README does not provide inverse scale parameters and original raw units, `AGB` is not available as actual physical plot mass, even though it is a numeric outcome. No standardization or inversion should be guessed from overall mean/SD alone.
