# Family-context deep-phylogeny interpretation boundary

Status: frozen before the corrected family-phylogeny result is opened.

This is a post-outcome complementary analysis. It does not alter the prospective 201-system results.

## If the primary exploratory association is significantly positive

Allowed wording:

> Family-level deviations in phylogenetic memory are not only repeatable across traits; they also show detectable continuity across deeper family phylogeny, with more distantly related families tending to differ more in their trait-memory context.

This would refine, not replace, the existing context-dependent interpretation. Trait identity would still fail the prospective held-out-family portability test.

Do not call this evidence for one universal evolutionary rate or a causal inherited mechanism.

## If the association is weak / non-significant

Allowed wording:

> The modest recurring family context is not detectably organized as a smooth function of deeper family phylogeny. At this resolution, trait-memory context behaves more like a family-level mosaic than a continuously inherited macroevolutionary regime.

This supports keeping the manuscript's current distinction between discrete lineage context and continuous deep-phylogeny covariance.

A non-significant result is not proof of no phylogenetic structure at other taxonomic scales.

## If the association is negative

Report it as unexpected exploratory structure. Do not construct a new adaptive mechanism from the sign.

## Manuscript role

Primary prospective results remain:
1. crossed repeatability;
2. held-out-family trait portability;
3. conditional family repeatability.

The family-phylogeny result may appear only as a complementary analysis or Discussion/Supplement result unless independently replicated.
