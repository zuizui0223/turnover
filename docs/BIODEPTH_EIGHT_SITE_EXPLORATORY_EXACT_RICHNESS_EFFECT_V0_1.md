## Separate exploratory data cohort (never retroactively qualified)
- A plot belongs to source-supported exploratory data if it lies in any original **site × exact sown-richness** level for which >=2 different planted **functional.richness** count values are present. Include **all** 230 original plot IDs meeting this criterion, across **all eight sites**; no minimum-per-site plot threshold for this *descriptive* programme.
- Original source-supported plot counts per site: Germany34, Greece22, Ireland46, Portugal10, Sheffield10, Silwood44, Sweden24, Switzerland40. Numbers refer to unique original plots, not independent annual replicates. Include all 3 source year measurements except missing biomass; never turn missing into zero. Original 34 measured zeros remain zeros. No outcome-based site exclusion.
- Guild indicators: grass, nitrogen-fixing legume and non-leguminous forb; FG count = exact sum of these. Original **composition** identifies a sown species assemblage and typically has replicate plots; group/cluster both year and replicate plot rows by original `site × composition` to avoid pseudoreplication.

## Exploratory descriptive and predictive estimands fixed before data effect
1. For each of eight sites separately, response `Y=log1p(original Shoots.biomass)`, two nested planned-sowing treatment models on identical records:
   - M0 `Y ~ C(exact species.richness) + C(year) + C(original block)`, omit block factor if original site has one block.
   - M1 = M0 + numeric `functional.richness` (1–3).
   - M2 = M0 + separate binary `grasses+legumes+forbs` (**never** include M1 count alongside all indicators). If full-rank, 2-df Wald test of 3 guild coefficients being equal; otherwise mark unidentifiable rather than delete an indicator. Source treatments remain as originally planted (not inferred from biomass/observed vegetation).
2. Fit OLS by site, and **composition-clustered** sandwich covariance for site-level M1 coefficient and M2 guild-equality Wald (all 3 source years and experimental replications retained). Record number of unique composition clusters and any rank/HC3 failure rather than invent p-values. Estimates under k≈10–46 original plots at certain sites are imprecise.
3. Across original sites, report **unweighted mean and median** of estimable M1 site slopes, number of positive site slopes, between-site SD and a 10,000-draw **resample-eight-sites** bootstrap CI for equal-site mean (seed **20261115**). No treatment plot-year inflation; do not mistake site bootstrap as a new global sample of climate zones. If any site-level M1 slope rank fails, retain it as a source failure and do not silently drop it.
4. As a site-support sensitivity, compare the eight-site equal-site summary to a **source-only** six-site subset where >=20 plots are supported summed across multiple richness levels (Germany/Greece/Ireland/Silwood/Sweden/Switzerland). This is not the original strict gate. For description only.
5. Temporal transfer diagnostic (not novel-site prediction): for each site train M0/M1/M2 on years 1,2 and evaluate on year 3 of **same experimental plots**. Use a numeric linear `year-1` in all models, not `C(year)` (test year3 unseen); retain original exact richness and block. Drop only models with structural rank deficiency and report their sources. Compute per-site `1-SSE_M1/SSE_M0` and `1-SSE_M2/SSE_M0` and group by source site. Do not tune feature set after outcome.
6. No causal legume or competitive-complementarity mechanism from binary sowing alone. All sources describe grassland experiments but weather, site soil and harvest schedule are not mutually controlled across sites. A positive 8-site mean conditional slope is retrospective evidence in this already published dataset, not novelty for BEF theory.
7. The prior two-study Jena/Cedar counts remain distinct: Jena 2003 exact-richness FG β+0.129 p≈0.168 (62 plots) and Cedar E120 1998 β+0.083 p≈0.544 (94 plots, Woody controlled). Neither is a source-independent replication of the 2005 BIODEPTH published effects. Comparisons of site-specific slopes require measurement/geometry caveats.

An individual site model that is rank deficient must be labeled support HOLD, not forced full rank by data-driven choice.
