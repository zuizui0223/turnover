# Jena TBE 2012: sample-size and design-matched shared-taxon purge reference (2026-11-27)

## Question and scope
Post-result sensitivity of PR #81. The strict species-disjoint analysis retained the same 84 held-out plots but removed training plots containing any held-out species, reducing training sample sizes from 55/55/56 to 36/27/47. All seven pooled gains then became negative. Is that decline unusual compared with removing the same number of training rows while preserving the fixed design? This is a conditional retrospective diagnostic, not a randomized test of species overlap, a new field experiment or a population confidence interval.

## Frozen comparison before examining matched-reference outcomes
- Reuse the original SHA-256-pinned Jena 2012 source, 84 mixtures, 24 monocultures, 3 trait pools, 7 endpoints and parent code from PR #81. Replay both the ordinary exact-composition-purged and strict species-disjoint combined scores to absolute tolerance 1e-10. Retain source literal Block HOLD and prefix proxies.
- For each heldout pool, ordinary training set excludes exact shared compositions as in the primary test. Strict training set additionally excludes every plot containing any heldout taxon. Reference samples draw without replacement from ordinary training **within training pool × richness × high/low FD × Plot-prefix proxy**, taking exactly the counts found in strict training. Zero-count cells contribute zero. This matches not only training size but design matrix rows, weights, FD balance and source prefix coding; no matched sampling on biomass or derived responses. All 28 heldout plots unchanged. Fixed M0 richness + prefix, M1 + high FD, equal training and testing pool×richness weights. Same samples for all endpoints. All 3 folds must remain full rank; no test rows deleted.

Count available exact stratum-matched subsets (product of combinations), number of draws with zero shared taxa, and aggregate shared-taxon-plot fraction. The strict subset must be included in the possible sample space; no forced overlap and no resampling of monoculture yields. No arbitrary reruns or sample rejection on outcomes. 
- Report for B, E, NDE, CE, SE, TDCE, DE: ordinary and strict pooled gain, matched-reference median and central 95% range (NOT a confidence interval), strict minus reference median in percentage points, percentile rank of strict gain (proportion reference draws <= strict with tie tolerance). Report analogous per-fold results and pooled M0 and M1 SSE summaries so changes in the baseline denominator are visible. No p-value or multiple-outcome significance claims; a strict score outside the central 95% reference range is only a descriptive signal of nonrandom training-composition effects under the matched reference, not a causal species-sharing effect. Do not call reference agreement proof of a sample-size-only cause: matched removal varies taxa, unmeasured trait composition and other unobserved design properties.
