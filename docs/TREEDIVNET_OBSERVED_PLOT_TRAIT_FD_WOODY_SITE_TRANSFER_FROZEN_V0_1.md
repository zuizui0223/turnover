## Fixed response and predictors (only when source preflight PASSES)

Original eligible observation grain = **unique original `site × block × plot`**, one response per plot, with original DS1 stand woody dry biomass positive or zero included; exact original source Figshare MD5 for DS1/DS2, original uploaded Table S1 SHA256 `245fdf2002240b905b032c9f444a9a359991212be93032637c9ed80a27516fee`, Table S3 SHA256 `c6458fa8f381090a77e529530d5cdb55d44ff3f1fc6e652f61ab2cb29b75d15b`. Source study Table S1 woody vs source traits years never changed, no source plot chosen by magnitude of biomass or sign of trait association.

- Y = `log1p(DS1.biomass_woody in Mg dry mass/ha)`. Not litterfall, NPP, wood density-derived trait target, annual carbon sequestration or plot-year repeated response.
- (n_{p}\) = number of jointly observed original DS2 planted species with positive **both** SLA and LNCM. Original source planted richness (R_{p}\) (not measured subset (n_p\)) enters baseline `log2(R_p)`.
- For original species i: `a_i=log(SLA_i)`, `b_i=log(LNCM_i)`. Per original whole-site fold, calculate **training-only** global mean/SD of the two log-trait values using one original species-row per source plot in training sites (all eligible plots). Apply the same transformation to heldout source-site species; no numerical outcome in scaling.
- `CWM_SLA` = equal measured planted-species mean standardized (a_i), `CWM_LNCM` = equal measured planted-species mean standardized (b_i). **No same-year biomass or basal-area weights**, to avoid response construction leakage.
- `FD_2D` = mean pairwise Euclidean distance `sqrt((z_a_i-z_a_j)^2+(z_b_i-z_b_j)^2)` across all unordered pairs of the **same original (n_p\) joint-measured source species**, no added published FDis from the paper.
- Baseline **M1** = intercept + original `log2(R_p)` + original 2-axis CWM (training-standardized using all eligible planted original species rows of training experiments). Candidate **M2** = M1 + source `FD_2D` as a single added covariate. Both use **source site-balanced weighted least squares**, with training plot weight `1/n_original_source_eligible_plots_in_training_site`; heldout plot prediction is source plot-specific but evaluation equalizes whole study sites.
- No extra quadratic richness, site fixed effect, biomass-derived light signal, external trait imputation, variable selection, species-set trimming or tuning after outcome. Before opening response, require all six/five training designs full rank and positive, finite source trait SD and FD variation; otherwise `MODEL_GEOMETRY_HOLD`, report no scored biomass effect.
- **Whole original study-site leave-one-site-out**, not plot-split CV. Freeze source population to all eligible sites with **≥8 original source-qualified plot-local trait observations** and at least **five original experiments**, with at least **80 total source plots**. Experiments with fewer source-qualified plots are still reported as SOURCE_HOLD and not opportunistically included/excluded based on effects. Original source site labels retained for aggregation.
- For heldout source site s: `G_s=1−SSE(M2,s)/SSE(M1,s)` (heldout log1p standing woody mass). Primary statistic equal-site mean `G=mean_s G_s`, and site-bootstrap 10,000 draw 95% interval seed **20261117**. Treat original sites as independent units, not 100+ plots/each species as independent ecosystem replications.
- **Positive source-transfer decision:** `G>0`, site-bootstrap CI lower >0 and **≥ceil(0.7×number of holdout original study sites)** individually positive. A positive point estimate without these is exploratory/nonsignificant; a negative average is not causal evidence against biodiversity functioning.

## Scope boundaries and escalation

The original study's *published* relationship of 283+17 species-site monoculture/external FDis to **NDE relative to expected monoculture biomass** is different from this new task, which predicts observed **DS1 standing woody biomass across unseen experimental sites** from same-site measured SLA+LNCM means and within-plot dispersion. It is a potentially interesting **predictive** ecological contrast, but both use the SAME original study and same underlying experiment, and so cannot be sold as independent replication.

Even after a source gate + outcome model PASS, result proves neither evolutionary rate, Blomberg's K, BIEN memory rho, species interactions, competitive/facilitative mechanism, natural selection nor transfer to global biomass. Original woody target derived from different allometric functions; leaf trait plasticity could itself respond to growth and light; unmeasured site-age/management and allometry effects limit external validity. Posthoc original source FD source selection is unavoidable, so stay exploratory.

The historically terminal global 201-family BIEN×sPlotOpen, strict 6-site BIODEPTH experiment and NEON authorization gates remain untouched. Do not merge to `main` or bypass source/API authentication. The original uploaded XLSX or copyrighted source data rows must never be committed.
