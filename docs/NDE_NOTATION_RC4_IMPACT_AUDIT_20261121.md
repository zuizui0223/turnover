# NDE記法の訂正とEvolution RC4原稿への影響監査

確認日：2026-11-21（JST）。対象：Draft [PR #64](https://github.com/zuizui0223/turnover/pull/64) の統合文書・証拠台帳、および利用者から提示されたRC4原稿2ファイル。編集前の統合ブランチは `58c536d6f7495f16d8d237a27354876b4502a3f8`。

## 1. 問題と訂正

文献間で異なるNDEの定義を一つの記号にまとめたため、比に対する対数式が、後続の符号付き超過量にも適用できるように読める状態だった。統合文書では以下の記法に分けた。

| 量 | 統合文書での定義 | 基準値・定義域 |
|---|---|---|
| 観測混植生産量 `B` | 同一区画の観測量 | 元の生産量単位 |
| 単植期待量 `E` | 対応する単植収量と植栽比率からの期待量 | `B`と同じ単位 |
| 符号付き超過量 `NDE` | `B − E` | 混植効果なしは0。負値を許す |
| 相対収量比 `R_mix` | `B / E` | `E > 0`。混植効果なしは1 |
| 対数相対収量 | `log(R_mix) = log(B) − log(E)` | 同一単位の数値で `B > 0, E > 0`。基準値は0 |

[Jensen et al. 2026](https://doi.org/10.1111/1365-2435.70320) のTable 2およびMethods 2.4、式(3)–(4)は、原著NDEを観測／期待の比と定義している。原著の名称・係数・結果はその比応答のまま保持し、本統合記法では `R_mix` と区別した。一方、[Loreau & Hector 2001](https://doi.org/10.1038/35083573) の加法分解を用いるJena/Cadotte再解析のNDEは符号付き超過量である。原著間で推定対象を置き換えていない。

加法恒等式は `B = E + NDE`、`NDE = CE + SE`。NDE・CE・SEに通常の対数を適用しない。比に対する対数式の正値条件と0値の扱いは、新しい解析を行う前に決める。今回の訂正は既存の凍結済み応答・変換を変更せず、将来の比応答案を遡及的な事前指定とも扱わない。

## 2. Jenaの調整差と生産量の水準を区別

同じ84混植区画・同じWLS仕様で求めた高FD−低FDの調整差を `Δ` と定義する。既存の点推定は次の算術関係を満たす（g乾燥重量/m²、表示は小数2桁）。

- `ΔB = ΔE + ΔNDE`：`+35.34 = −33.62 + 68.96`
- `ΔNDE = ΔCE + ΔSE`：`+68.96 = +27.81 +41.15`

負なのは期待量の**調整差** `ΔE` であり、単植期待量 `E` が負という意味ではない。5成分すべての既存95%区間は0を含む。同じ線形推定による恒等式の一致は、FDによる生態学的な相殺・補償機構の実証ではない。

照合元は [PR #74の保存済み集計結果](https://github.com/zuizui0223/turnover/blob/c104ef231e03dec78d9d2b3f2739372f1563999c/results/jena_tbe2012_original_84plot_expected_mono_NDE_mass_accounting_v0_1.json) と [同じ版の計算コード](https://github.com/zuizui0223/turnover/blob/c104ef231e03dec78d9d2b3f2739372f1563999c/scripts/analysis/jena_tbe2012_original_monoculture_CE_SE_partition_v0_1.py)。コードは `Y.sum() − M.sum()/n` をNDEとし、NDE・CE・SEを変換せずWLSに入力している。今回は原観測データの再取得・モデル再推定を行っていない。

証拠台帳のJena項目では、未通過なのが**本再解析での物理ブロック対応の確認条件**であることも明記した。原著実験の無作為化そのものが失敗したという判断ではない。未認証のA/B/C接頭辞、種組成とFDの同時変化、単植参照値の標本誤差を含まない区画bootstrap、単一実験という制約を保持した。

## 3. 提示されたRC4 Word/PDFへの影響

対象は *Repeatable lineage context and scale-dependent trait portability in plant phylogenetic memory* の匿名原稿。PDFは19ページ。本文・参考文献・図キャプションを含む全文と、Wordの133段落（非空130段落）を照合した。

| 確認項目 | 結果 |
|---|---|
| 研究対象 | 201科×形質系、45科、12連続形質。PDF pp1,3,4,14で一致 |
| `NDE` / `net diversity effect` | 両ファイルとも出現なし。訂正対象のNDE式なし |
| Jena / Cadotte | 両ファイルとも出現なし |
| `biomass` | 両ファイルで2箇所。いずれも因果関係を主張しない制限 |
| `FD` | 両ファイルで1箇所。`K→FD→biomass` の因果的証拠を提供しないという記述 |
| 記憶の応答 | `rho = Spearman(patristic distance, pairwise absolute trait difference)`。PDF p5の本文式 |
| Figure 3 | PDF p19。科を留保した予測のSSE改善であり、NDEやバイオマス解析ではない |

重なる記述はPDF p13（印刷行290–293、Word P107）とp14（行299–304、P110）。前者はAusTraitsのKと本研究のrhoの推定対象を区別し、後者は因果的なK→FD→biomassの証拠を提供しないと明示する。今回のNDE記法訂正を理由とするRC4本文の置換は必要ない。

WordとPDFは、PDFの印刷行番号・ページ番号、空白、表示用箇条書き記号を除き、Unicode NFKCを適用した本文列が一致した。文字の大小・数字・数式記号・句読点を保持した比較で、両者26,022文字、正規化後SHA-256は `09228161cfd822e5737c1c14c647555974e7c5ca30122bb2e9bd7ba5f38ac841`。

PDFのpp1,5,13,14,17–19と3図を目視確認した。これは対象の内容・式を照合する監査であり、全ページの組版承認ではない。Wordのページ数メタデータは古いため、ページ数にはPDFの実ページ数を使用した。

原稿ファイルは変更していない。取得時と監査後のSHA-256が一致した。

| 提示ファイル | SHA-256（取得時＝監査後） |
|---|---|
| `Evolution_RC4_Anonymous_Manuscript.pdf` | `e66507660be52d8bdc9637d555fb9bdb0d0b254367a2685f16ca73e07a396bb5` |
| `Evolution_RC4_Anonymous_Manuscript.docx` | `80007c68286e75c34fa1abdd3f8453a069e93021111fb8b4e5cba7dab3785574` |

この結論の対象は上記2ファイルであり、未開封の投稿ZIP、別版原稿、補足資料全体の完全性を保証するものではない。RC4の既存Draft [PR #67](https://github.com/zuizui0223/turnover/pull/67) とは別の編集作業として記録する。

## 4. 検証と現在地

3つの既存ファイルに対する差分を独立レビューした。証拠台帳は21件・21個の固有IDを保持し、変更はJena項目の説明文のみ。全observations、estimand、status、引用先、および他20項目は編集前と一致する。Jenaの5成分とCIは固定版の集計結果と照合し、全区間が0を含むことを確認した。

記法・調整差の説明の訂正と、提示RC4原稿への影響確認は完了。新しい効果の推定、証拠区分の格上げ、FD単独の因果効果、系統的記憶からバイオマスへの媒介鎖は追加していない。既存の科学的未解決点は、物理ブロック対応、単植基準の不確実性、および独立実験への一般化である。
