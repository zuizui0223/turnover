## Predefined estimands and preprocessing
- Biological unit = distinct original **plot × year** for source 2010 biomass, repeated across original plot; geographical replication = original field **site** (at most eight). One chosen height trait and only initially planted species, even if species did not persist by years 2/3. Any unknown species height excludes that species from trait calculation, but only plots with ≥3 height-documented original planted taxa and ≥80% coverage are eligible.
- Transform height **prior to any biomass access** as `h=log(Plant_height_max_m)` (no imputation, species values fixed across plot/year). For each original plot:
  - **CWM_height** = equal-weight mean of valid original sown species h (not harvested-biomass-weighted).
  - **FD_height** = equal-weight mean absolute *pairwise* difference `sum_{i!=j}|h_i-h_j|/(k(k-1))` for k≥3 valid original planted taxa. This is a one-axis mean pairwise height distance; do not misleadingly call it multivariate FD or convex hull/hypervolume, and note that it differs from classical abundance-weighted Rao Q.
  - **Coverage** = k/original source planted species richness (only ≥0.8), species count k. Source coverage is not a model outcome.
- Keep source measured 2010 response Y=`log1p(Community aboveground biomass g/m²)`; source year1/2/3 remain repeated observations of same original plot. No annual NPP inference and no GIFT maximum height as an actual plot measurement.
- **M0** baseline: intercept + `log2(original planted richness)` + squared `log2(original planted richness)^2` + original planned grass/forb/legume **three binary guild identities** (NOT their redundant sum) + original source year2/year3 dummies. This model is fixed for any site heldout; *no site identity fixed effects* because a heldout site has no estimated intercept. Treatment flags come from original Hector 2010 guild flags, cross-checked against original 2005 sown design.
- **M1** = M0 + original planned CWM_height, z-standardized using training rows only.
- **M2** = M1 + original planned FD_height, z-standardized using training rows only. **Primary contrast:** M2 vs M1; isolates added *dispersion* beyond mean height and sowing/guild context. This is not a causal intervention or test of original phylogenetic-memory rho.
- Fixed heldout validation: **leave-one-original-BIODEPTH-site-out**. Train on all other eligible sites, evaluate heldout site exactly once, without feature selection, no random folds by plot-year. Fit ordinary least squares from full-rank design, no tuning and no source year leakage in trait features. All models evaluated on identical original complete-case plot×year values.
- **Primary score** site-equal mean of `G_s=1-SSE(M2,s)/SSE(M1,s)` across all eligible original sites (each geographic site 1 vote, no abundance weighting). 10,000 site-level bootstrap resamples (seed 20261115) of the **G_s** numbers, 95% percentile CI. Also report n sites with G_s>0 and pooled SSE improvement for transparency. Positive association support requires site mean G>0, bootstrap lower CI>0 and ≥5 sites with G_s>0. If CI overlaps 0 report **not established**.
- Planned secondary gains `M1 vs M0` (mean height), `M2 vs M0`, same test cells/heldout sites; descriptive only, no separate significance search.
- Within-cohort source completeness sensitivity: recompute when **all original planted species** have GIFT height; if <40 original plots across ≥4 sites, label sensitivity NOT ESTIMABLE. Do not substitute a different trait to rescue.

## Interpretation and known boundaries
1. Site-specific GIFT height completeness is uneven (Greece 0 eligible under prior 174 plot gate); do not silently call seven qualifying sites representative of all eight or worldwide grasslands.
2. The original source only has three realized biomass years; species maximum heights are values from potentially other geographies/habitats, so one-axis dispersion is a surrogate of expected structural niche/height contrast, not observed canopy heterogeneity or ecosystem nutrient complementarity.
3. The pre-existing BIODEPTH original strict planned FG-count support **HOLD 1 of 8 sites vs >=6** remains unchanged, as does original global sPlotOpen×GIFT×BIEN phenotype-memory to PD–FD 201 systems, and NEON auth source.
4. Earlier original Spehn/Hector work already examined biodiversity–biomass/legume effects; even a new positive heldout GIFT height association is a **retrospective analysis with nonindependent studies and potential trait-literature overlap**, not discovery of an ecological law or a causal mediation pathway.
5. No explicit original GIFT source-provenance outcome may be modified after observing this model. If source or model gates fail, return HOLD with code and aggregate source diagnostics rather than forcing a result.
