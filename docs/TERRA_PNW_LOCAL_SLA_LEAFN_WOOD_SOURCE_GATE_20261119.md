# Source-first admission: TERRA-PNW local SLA and leaf N -> wood carbon stock
**Frozen 2026-11-19 before original source files are opened. No ecological effect is authorized in this branch.**

## Why this new candidate
NASA/ORNL DAAC DOI [10.3334/ORNLDAAC/1292](https://doi.org/10.3334/ORNLDAAC/1292), Law & Berner (2015), descriptor paper in *Scientific Data* [sdata20162](https://doi.org/10.1038/sdata.2016.2), reports **1,296 individual plant leaf-trait observations**, **266 stand-level carbon/biomass rows** and **35 tree/shrub species**, sampled in **six project programmes across Oregon and northern California**. Published counts are **NOT verified original join counts** and 266 plot-year rows are not 266 independent geographic ecosystems.

Unlike archived plot-only CWM sources, authors describe original **co-located plant observations for SLA and leaf N** and plots with overstory species/basal-area fractions; this makes it an *actual candidate*, not a source-qualified joint species FD test. Original paper explicitly notes repeated plots can have a different `PLOT_ID_ALT` and only lists the **top four overstory species**; species identities must be matched by the documented original six-character genus-species abbreviations, not invented from source names.

## Fixed origin and source schema
- Leaf original file (paper terminology) `NACP_TERRA_PNW_leaf_trait_dataset.csv`. Required fields: `PROJECT, YEAR, PLOT_ID, GENUS, SPECIES, SLA_PSA, LEAF_NITROGEN`, with original missing sentinel `-9999`. SLA_PSA is **cm² projected surface area per g leaf carbon**, not generic cm²/g dry mass. Leaf nitrogen is **percent dry leaf mass**. Do not substitute units.
- Stand original file `NACP_TERRA_PNW_forest_biomass_productivity_dataset.csv`. Required: `PROJECT, YEAR, PLOT_ID, CLUSTER, ECOREGION, AG_BIOMASS_TREE_WOOD_AS_CARBON`; source up to 4 overstory abundance pairs `SPP_O[1..4]_ABBREV` + `SPP_O[1..4]_BASAL_AREA_FRACTION`. The raw biomass unit is **g C m−2**, an *estimated standing stock*, not dry-mass NPP.
- Target response is specifically **AG_BIOMASS_TREE_WOOD_AS_CARBON**. The same original authors calculated leaf biomass partly using SLA/LMA. To avoid a direct algebraic trait→leaf-stock linkage, do **not** use their foliage or total biomass as the primary response.
- NASA AWS public registry currently labels `ornl-cumulus-prod-protected/nacp/NACP_TERRA-PNW/data` as controlled access (Earthdata credentials). Public catalogue metadata do NOT imply anonymous data-download authorization. Source script must make only an authorized **anonymous official-source attempt**, terminate as ACCESS_HOLD on 401/403/redirect-to-login, and never try accounts, private mirrors, signed token extraction or bypasses.

## No-outcome source gate (exact, stop on fail)
1. Verify original source links and *actual* CSV bytes in bounded, anonymous official archive only; SHA256 locally; never redistribute original rows. CSV header and unit-row interpretation must match author schema; missing `-9999`, blank, NA discarded without zero imputation.
2. Original join key = **(PROJECT, PLOT_ID)**, matching exactly (no fuzzy keys). Treat differing `PLOT_ID_ALT` and repeated site co-ordinates as potential non-independence and audit them separately; repeated campaigns from one site are **not** independent plots. Flag cross-project resampling. If exact key cannot link, HOLD. No coordinate-nearest rescue.
3. On each qualifying stand observation, aggregate directly measured leaf SLA_PSA and leaf N per **(PROJECT, PLOT_ID, GENUS, SPECIES)**, using unweighted valid individual medians. Keep both traits positive and finite. Pair only with stand date gap **≤2 calendar years**, choose absolute closest stand year; if more than one equal-closest year select earliest original year deterministically; if duplicate stand keys in that year remain, stop and report ambiguity. Do not use published TRY or study-wide substitutions.
4. Original overstory species×basal-area entries: only source-verified positive fractions and nonmissing six-letter `3 genus + 3 epithet` abbreviations; unique species crosswalk only if exactly **one** source species corresponds to one code, collision anywhere makes `TAXON_CROSSWALK_HOLD`. If all required species cannot be uniquely matched, do not silently infer identities.
5. Per stand coverage: ≥**2** overstory species have **both** directly observed local SLA and leaf N; **≥80% of summed positive listed source basal-area fraction** must belong to uniquely matched, dual-trait measured species on source plot/date. Explicitly report missing or unlisted basal-area fractions. Do not treat the four dominant overstory taxa as the full community.
6. Original eligible **≥80 distinct plot identities**, **≥30 source-verified original named species** in eligible trait-bearing plots, **≥5 original PROJECT groups with ≥8 eligible distinct plots each**, with each programme independently classified by exact `PROJECT` category. A programme is NOT an independently published replicated study; even an eligible result is regional six-project predictive transport, **not a global forest law**.
7. All gates are pre-outcome, strictly fail closed. Source-only aggregate diagnostics can report per-project plot counts and input row counts, unique eligible taxon count, distributions of matched year differences and missing support, but **no response values, species names, plot IDs, coordinates, FD or biomass effect coefficients**. No model fit on this lane.

## Prespecified inference if and only if this new source gate eventually passes
**Not authorized in current source-only PR.** Separate *prospectively frozen* independent-project held-out prediction only: M0 original stand age + climate + spatial/environmental region and planted/observed species richness + mean SLA/leaf N; M1 adds two-dimensional within-plot original observed local pairwise dispersion. Exact model specification requires original source covariate support; no formula is chosen or fitted in this branch. Six projects and shared geography make it exploratory regional generalization at most; do not pool with TreeDivNet or BIODEPTH because their FD and stock units differ.

**Separate phylogenetic K mediation cannot run here.** Published total **35** tree/shrub species fails original globally locked **≥12 families ×20 independently observed species**. Neither imputed K nor previously fitted BIEN family scores may be attached to this dataset to bypass taxon/grain constraints.

Using these original authors' data for a different held-out-project prediction is **not** a new independent biological experiment and should not be called an independent external replication of the published authors' same claims.
