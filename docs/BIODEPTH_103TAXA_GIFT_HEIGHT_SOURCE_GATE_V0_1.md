# BIODEPTH original 2010 species×independent quantitative trait source: GIFT v3.1 source-only eligibility

2026-11-15, prospective **source-only** test after the source biomass edition incompatibility was discovered, and **after** previous BIODEPTH guild/biomass effects were opened. Any later trait-FD/biomass result remains exploratory/post-result. The original 201-system BIEN/sPlotOpen/GIFT global source gate remains **HOLD** and may not be rescued by new data.

## Valid data source and biological units
- Original Hector et al. 2010 BIODEPTH **species×plot×year** source `BiodepthSpeciesBiomass.txt` SHA256 `ebe677c639ef4603bc1ed50d49e7440588683e7696be230c0cbfff7d6b22b816`, original 2010 site/ecotype source `BiodepthSpeciesCodes.txt` SHA256 `02ad483f727d4d10c10be7e7fe83e9e66c42803d6d08956d9397001dbf32f11b`. Original 5802 species-year rows = 1934 original **planted species×plot** records ×3 source years. 480 original plots, eight original field sites, original 186 site/ecotype codes map without ambiguity to **103 Linnaean genus+species names**.
- Original 2010 hierarchical `BiodepthBiomass.txt` Species, Group and Community all add exactly at source numeric complete cases; use the **2010 species/group/community single self-consistent response edition only** when/if effects are estimated. 2005 `Shoots.txt` differs >100 g/m² in 346/1415 cases; never mix it with 2010 relative species biomasses to construct an FD predictor for a 2005 response.
- **Original SOWN presence** at each plot is derivable from the 2010 source row roster of each species in year1, irrespective of whether its biomass is zero. The biomass value is not used for any predictor; species with biomass zero or NA still count as sown if they are on original roster. Do **not** use 2010 biomass weights to predict 2010 Community biomass — that would condition on outcome.
- Only after exact family/tree source qualification could one explore the original family-specific trait-memory rho; neither BIODEPTH nor GIFT by itself supplies this.

## Public independent trait-catalog candidate
- GIFT API v3.1 https://gift.uni-goettingen.de/api/extended/index3.1.php ; original API `query=species` contains accepted scientific names `work_species` and `work_ID`; trait `query=traits&traitid=1.6.2&biasref=0&biasderiv=0` is **maximum whole-plant height** (scalar). Reuse existing GIFT API schema and conservative distinct-value rules from `analysis/pd-fd-biomass-source-gate-20261114`, scripts `audit_splotopen_gift_family_eligibility_v0_1.py`. The GIFT data source may share original literature with BIEN/AusTraits/TRY; **trait-source independence is NOT established by a GIFT match**.
- Match only exact normalized *original* 2010 Linnaean binomials to unique accepted GIFT `work_species` with unique `work_ID`. Do not use secondary Byrnes' `all_biodepth.rda` 7 unresolved abbreviations; no silent taxonomic synonym assignment. Split odd infraspecific concatenations only with documented authority, in a future differently scoped alias audit.
- For height, use only finite positive numerical GIFT trait values and unique distinct trait values per GIFT `work_ID` as a **conservative lower bound**. Also report wider **any positive height** coverage to expose selection caused by multiple legitimate sources; do not select a convenient measurement post-biomass.
- No missing trait values imputed, no same-year abundance weighting, no community FD estimated in this gate. Source audit rows and API total counts/hashes, not raw trait records, committed.

## Strict independent exploratory eligibility thresholds, fixed before GIFT retrieval
1. Exact accepted GIFT name linkage **≥80/103 named original species** (≥77.7%), and at least **55/103** original taxa with unambiguous finite positive GIFT maximum height. These are source-support thresholds, not biological test p values.
2. At least **four of eight original BIODEPTH field sites** must each have **≥8 original plots** with ≥3 original planted species possessing exact-unambiguous height and ≥80% of originally planted species represented by independently sourced trait height. At least 60 original plot IDs in the whole study must pass those per-plot thresholds.
3. Report site-by-site plot coverage, planted-richness strata, proportion of original sown species with positive numeric trait values and effective original taxon count, including original true source-raw out-of-support taxa. If these thresholds fail, SOURCE_HOLD. Do **not** import a second trait post-outcome to rescue a height-only failed gate.
4. If all pass, only authorize a new *one-axis height FD* feasibility design; the actual ecological association with 2010 measured original Community biomass is **not yet authorized**, and the source trait bibliographic overlap and height units still require auditing. This is **not multivariate FD or phylogenetic prediction**.

## Cross-experiment boundary
Jena 2003 species height and Cedar Creek 1998 grassland categories have different responses/species pools. BIODEPTH's source names and heights do not make their plant FD comparable across sites or other experiments by themselves. All established Jena/Cedar/BIODEPTH retrospective source findings and old biological interpretations remain unchanged until genuinely tested new effects with independent data.
