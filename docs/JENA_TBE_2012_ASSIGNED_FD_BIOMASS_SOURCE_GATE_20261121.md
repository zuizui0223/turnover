# Jena Trait-Based Experiment (TBE) 2012: assigned functional-dissimilarity treatments × biomass — original source gate
**Freeze: 2026-11-21 before opening original PANGAEA numeric biomass rows in this lane. SOURCE ONLY; no new ecological effect authorized.**

## Why this original experiment (not ordinary Jena Main)
The TBE was designed to manipulate **plant species richness and designed trait dissimilarity** across 3 distinct species pools reflecting (S) spatial resource use, (P) phenology, and (SP) both. Across 138 original 3.5m square grassland plots in 3 original field blocks, planted richness levels 1, 2, 3, 4, 8 were crossed with designed within-pool FD levels 1–4 where feasible. Plots were planted autumn 2010 / resown summer 2011, 2012 harvested twice, late May and August. This is ONE experimental station and NOT three independent experiments. Note published site descriptions differ slightly on quadrat/plot size, so original dataset is source of truth for biomass area units. The source authors already reported positive greater overyielding/complementarity for species pools covering BOTH temporal and spatial traits and competition effects in spatial pool; **not an original new causal discovery**.

Primary published original source [PANGAEA DOI 10.1594/PANGAEA.876725](https://doi.org/10.1594/PANGAEA.876725), Wagg et al. 2017: source fields Plot, Month, planned `wFDc`, original planted species number, original Species Pool and original Block, weeds/dead/unidentified dry standing biomass, up to 20 individual **sown species** g dry mass m−2; original missing sentinel `-9999`, unsown species blank. License CC-BY-3.0. Download public original tab-separated: `https://doi.pangaea.de/10.1594/PANGAEA.876725?format=textfile`.
Source second original [PANGAEA 10.1594/PANGAEA.876730](https://doi.org/10.1594/PANGAEA.876730): species-specific **monoculture-measured traits** (SLA, height, root traits only some pools), not all plant trait values measured before planting. Third JEXIS original "Design data of Trait-Based Experiment" dataset ID 739 contains planting-time PCA/trait design (access and original match unverified). Do NOT substitute 2012 measured traits as a pretreatment variable unless explicitly labelled postplanting; the intended treatment is original *assigned FD level* `wFDc`.

## Separate next effect lane if and only if source gate passes (currently no outcome opened)
- The **assigned-species-composition treatment** conditional on pool, planted richness, and field block can in favorable design support a more defensible *treatment* contrast than correlating measured post-planting community FD with biomass.
- Prespecified outcome annual original sown plant dry biomass (2012 May+August) on **same plots**; treatment high-vs-low designed `wFDc` within eligible original pool×richness strata; blocked OLS coefficient or exact source-scheme conditional permutation of assignment across plots **ONLY when original randomization/assignment mechanism verified**, otherwise site/block-stratified nonrandom contrast with permutation only a descriptive reference.
- Treat full original plot as unit. Repeated months are two components of each annual plot; never sample 276 monthly rows as independent. Site-level or pool-level SE with only 3 pools cannot establish global treatment effect. Original design selected species pools intentionally and mixes species identity, so **FD-specific numerical causal mediation is NOT identified**, even if treatment allocation was randomized spatially.
- Beyond-randomization *selection vs complementarity* partition needs SAME source species monoculture yields per species and same 2012 harvest months. Do not infer from plot response alone. Monoculture trait dataset 876730 is not necessarily monoculture **production**; original mixture dataset has monoculture plot yield, but some taxa may have no monoculture control within same pool. Require exact plot species roster/monoculture mapping; no approximate cross-pool borrowing.
- No model refit of original Wagg 2017 claims rebranded as novel independent discovery. Novel analysis could investigate **whether experimentally assigned spatial versus temporal complementarity differs in a controlled, identical-resource, richness-matched biomass endpoint**, but the published Wagg study already addressed much of it; candid retrospective process test only.

## Scientific limit / chain
No continuous FD randomized independently of species identities; experiment manipulates **assigned mixtures chosen based on traits**, so the treatment may include species identity and life-history differences. This study is *at Jena* but a separate planted design from 2002 Jena Main, and is not an independent climate/site replication. No `BIEN rho/K→FD→biomass` causal mediation possible from 20 source species / 3 pooled treatment communities.
