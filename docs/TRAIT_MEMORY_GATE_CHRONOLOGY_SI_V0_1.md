## Qualification of the shared empirical core

The 201-system core itself was selected before any real family × trait memory rho was opened:

1. Temporal structural support.
2. Trait semantic validity.
3. S3 and prune-only phylogeny crosswalk.
4. Known-truth temporal geometry informativeness.
5. Family-degree >=2 and trait-degree >=5.
6. >=12 families, >=4 traits and one connected family–trait graph.

The resulting core contains 201 family × trait systems, 45 families and 12 continuous traits.

## Preserved failed questions

Two questions are intentionally retained as negative qualification results rather than retrofitted:

- the generalized time-space turnover programme;
- the trait-versus-lineage variance-ratio classification.

Neither threshold was relaxed after failure, and neither failed question was recovered by reinterpreting later repeatability estimates.

## Effect identity

The three real-effect execution routes used by repeatability, portability and conditional-lineage analyses produced identical 201-system effects:

- same family × trait keys;
- maximum absolute S3-rho difference = 0;
- maximum absolute prune-only-rho difference = 0;
- maximum absolute reused informativeness-lambda difference = 0.

Evidence: results/trait_memory_context_synthesis_v0_1/effect_identity.json.

## Interpretation rule

The post-outcome synthesis introduces no new p-value, threshold, filtering step or model selection. It combines only the separately qualified results and preserves all earlier nonclaims.
