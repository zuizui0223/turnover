## Fixed outcome-blind source qualification for a NEW exploratory country transport test

- Grain: one original `plot_uniq_ID`, exactly original 276 source rows; unique, nonempty original source keys and documented `country` labels.
- **Five independent country domains** (Benin, Burkina Faso, Ghana, Togo, Ethiopia); require at least **12 plots/country** and ≥**200 source plots** with all original full-covariate numeric fields and standardized response present. Countries are domains, NOT guaranteed independent field sites; source area/plot ID provenance must be kept distinct.
- Verify per original plot positive `plot_size_ha`, valid source growth labels `growth` with exactly two original classes, exact original `sd_agb.mg.ha`, `sd_fdis`, `sd_richness`, `sd_cwmwd`, `sd_cwmsla`, `sd_cwmlnc`, `sd_cwmhm`, `sd_prec`, `sd_temp`, `sd_plots`. Values may be NEGATIVE because already author-standardized. `age_years` has source missingness in old-growth forests (104/276 originally nonmissing), so do **not** impute/use age as a complete predictor.
- Before opening original AGB responses as a statistical Y, verify that for **each country held out**, training predictors have rank 10 including intercept/growth (M0) and rank 11 after adding author-original `sd_fdis` (M1), with finite positive standard deviations for all continuous predictors. If a source fold is not full rank, return `MODEL_GEOMETRY_HOLD`, do not remove a country/feature after effects.
- If source count or rank gate fails, **no new effect** and no ad hoc threshold. If pass, a separate future outcome contract can use a *fixed* comparison: M0 = intercept + source growth class + original source-standardized richness, **CWM wood density, max height, SLA, leaf N**, standardized plot area, climate temperature and precipitation; M1 = M0 + original author-published **standardized functional dispersion `sd_fdis`**. Train 4 countries, predict heldout 5th; each training country equal total WLS weight; site/country-equal heldout `1−SSE(M1)/SSE(M0)`; five-country bootstrap with 10,000 seed 20261118; a positive transferable increment requires >0 mean, CI lower >0 and ≥4/5 positive country scores. Original source response is already standardized across all plots, never raw Mg/ha.
- Do **not** include source original `Hd/Hh` structural diversity in this first baseline: the estimand is FDis beyond species richness and CWM under site/climate, *not FDis over a mediator structural-diversity adjusted model*. A different structural pathway would require a separate independent study.
- Report original country plot counts, positive biomass/standardized response validity, source growth-class distribution and predictor cross-country means/differences without original row values, never export original plot IDs, original species (none), raw AGB, or trait numeric values.
- In causal/statistical interpretation: published FDis itself may use species-trait means compiled from databases; source lacks raw measurement identities, abundance matrices, source year-by-plot, and original species-level traits. A successful original country-generalization is at most prediction of a **precomputed community-level functional index**, not phylogenetic K, original local-trait measurement replication, a new independent BEF experiment, causation, direct allometric biomass measurement, or universal functional diversity law.
