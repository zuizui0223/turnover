# Mangal source-semantic adjudication v0.2

## Decision

**MANGAL_SOURCE_SEMANTICS_PASS**

All 13 taxonomy-support programmes can be assigned a source-faithful interaction family and focal-guild rule using dataset descriptions and original-reference metadata alone.

No interaction edge, interaction type/value, node name or taxon name was opened for this adjudication.

## Frozen classes

- **pollination mutualism** — 3 programmes; focal guild = plant
- **host parasite / parasitoid** — 2 programmes; focal guild = host
- **consumer-resource food web** — 8 programmes; focal guild = consumer

The predeclared label `host_parasitoid` was too narrow for the flea–small-mammal Hadfield system. A versioned pre-edge amendment broadens only that label to `host_parasite_or_parasitoid`. No threshold, dataset or outcome rule changed.

## Why this matters

The programme will not infer biological direction from whatever edge pattern later appears.

Before edges are opened:

- pollination networks already have plant as the focal guild;
- flea/parasitoid networks already have host as the focal guild;
- food webs already have consumer as the focal guild.

Interaction type is therefore a moderator fixed upstream of the response.

## Next gate

Taxon names/ranks may now be opened solely to test phylogenetic feasibility. Interaction edges remain sealed.
