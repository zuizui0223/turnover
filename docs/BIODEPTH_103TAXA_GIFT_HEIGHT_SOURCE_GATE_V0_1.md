## Strict independent exploratory eligibility thresholds, fixed before GIFT retrieval
1. Exact accepted GIFT name linkage **≥80/103 named original species** (≥77.7%), and at least **55/103** original taxa with unambiguous finite positive GIFT maximum height. These are source-support thresholds, not biological test p values.
2. At least **four of eight original BIODEPTH field sites** must each have **≥8 original plots** with ≥3 original planted species possessing exact-unambiguous height and ≥80% of originally planted species represented by independently sourced trait height. At least 60 original plot IDs in the whole study must pass those per-plot thresholds.
3. Report site-by-site plot coverage, planted-richness strata, proportion of original sown species with positive numeric trait values and effective original taxon count, including original true source-raw out-of-support taxa. If these thresholds fail, SOURCE_HOLD. Do **not** import a second trait post-outcome to rescue a height-only failed gate.
4. If all pass, only authorize a new *one-axis height FD* feasibility design; the actual ecological association with 2010 measured original Community biomass is **not yet authorized**, and the source trait bibliographic overlap and height units still require auditing. This is **not multivariate FD or phylogenetic prediction**.

## Verified source result and unit addendum (original thresholds unchanged; no outcomes opened)

Original [GIFT R package tutorial](https://biogeomacro.github.io/GIFT/articles/GIFT.html) explicitly identifies trait `1.6.2` as `Plant_height_max`, **type numeric, Units = metres (m)**. It further explains that this species-level maximum vegetative height is aggregated using the **maximum** among available source measurements; unlike a raw field plot height, this is a species-level upper-bound trait, and the raw reference IDs can be queried. The observed API `query=traits` returned already aggregated trait records, so the zero multiple-value conflict count does not certify that source studies were free of differing height values. Bibliographic trait-reference provenance and potential overlap with TRY/BIEN or original 2010 authors remain to be examined separately.

Predeclared source support **PASS** in [Actions #43716315298](https://github.com/zuizui0223/turnover/actions/runs/43716315298), artifact #14162907414 SHA256 7309a083b7bc91cc87ee6e3bd3f47f99d7b266916a66ca39da5762536463ce00: `GIFT species` 372,046 accepted records, `trait 1.6.2` 70,231 records; **93 of 103** original BIODEPTH taxa exact accepted matches, **88/103** positive numeric maximal-height values; **174/480 original sown plots** pass ≥3 trait-observed species and ≥80% originally sown height coverage; **seven/eight original sites** each have ≥8 such original plots. Greece had **0** eligible plots under these fixed filters. The 80/55/60/four-site thresholds were fixed before opening GIFT values.

This provides a **source geometry basis for one-axis planned *height dissimilarity***, not a first finding that multi-axis FD predicts biomass, not original phenotype-evolutionary-memory `rho` and not a valid across-eight-sites model with Greece silently excluded. Source selection biases and reference independence need a separate gate, and any outcome analysis using original Hector et al. 2010 biomass remains explicitly exploratory/post-result.
